## Absorbed Structuralist source

The living `skills/structuralist/` package was absorbed from Structuralist
commit `837f9442aa6a914afb4f5839a8d3f8278c693f47`. Its one-time source and tree
identity are recorded in the development laboratory's internal import record;
that record is not needed to use or redistribute the released package.
Copyright in the imported
material remains with Structuralist contributors under the path-specific terms
above.

Mindflow modified `skills/structuralist/SKILL.md` and
`skills/structuralist/references/practice-realization.md` at absorption to state
the package's new position as Mindflow's future-facing Evolve methodology. The
validation scripts were adapted to coexist with Mindflow's frozen
`integrate-mindflow` package and repository layout. Later changes are living
Mindflow development rather than synchronized copies of the former repository.
