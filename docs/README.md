# Mindflow guides

These guides describe the [2026.10.27 source beta prerelease](https://github.com/bearxiong2k/Mindflow/releases/tag/v2026.10.27)
and project format `2026-10-27`. No guide requires access to the private
development laboratory.

| Guide | Purpose |
| --- | --- |
| [Installation](installation.md) | Install the CLI, optionally install Structuralist, or build the local GUI. |
| [Repository tour](tutorial/README.md) | Inspect a working Region before changing your own project. |
| [First use](quick-start.md) | Create a small Region and review deliberate adoption. |
| [Semantics](semantics.md) | Understand Structure, Opening, Evolve, and their boundaries. |
| [Project format](project-format.md) | Author the single manifest over ordinary files. |
| [CLI](cli.md) | Find inspection commands, output behavior, and mutation entry points. |
| [GUI](gui.md) | Navigate Structure, Files, Reader, Evolve, and measurements. |
| [Structuralist](structuralist.md) | Install and explicitly invoke the optional methodology skill. |
| [Rationale](rationale.md) | Understand why Mindflow keeps the maintained account bounded. |

Start with [installation](installation.md) and the [tour](tutorial/README.md).
Source provenance is recorded in [`release-source.json`](../release-source.json);
release status and changes belong in the [changelog](../CHANGELOG.md).
