# Project evolution

Events are ordinary Markdown discussions and authored summaries selected in
`MINDFLOW.yaml`. They preserve developments in understanding, including open
questions; current governing commitments remain with their ordinary owners.

Start with [the initial project direction](initial-direction.md). Add a summary
file with ordered child Event references when a group would help readers.
Timeline reads these files; authors and agents edit them directly. This folder
is one convenient arrangement, not a Mindflow requirement.
