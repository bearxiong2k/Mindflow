# Browsing question

Returning to a collection raises two different needs: resuming a recent visit
and comparing observations from the same place. Which should shape the default
view?

A recent-visits list makes resuming work direct, but separates repeat visits to
one place. Grouping by place supports comparison, but adds a choice before a
reader can return to yesterday's notes.

At this point we do not know which need should lead. Try both with a small
collection containing repeat visits before changing the browsing commitment.
The bounded task is to choose a default and preserve access to every note.
Start with paper layouts; navigation effort is an initial comparison, not a
substitute for checking whether the reading task succeeds. Keep the useful
observations and their limits after the temporary worksheet is absorbed.
Keep this question distinct from whether Fieldbook should organize fieldwork;
that remains outside the [project boundary](../project.md).
