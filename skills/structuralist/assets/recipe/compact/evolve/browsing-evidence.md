# Browsing evidence

The [paper walkthrough](../evidence/browsing-walkthrough.md) exposed the
difference behind the [browsing question](browsing-question.md): returning to
yesterday's visit benefited from a direct entry, while comparing visits needed
the observations themselves. Place grouping narrowed the collection but did
not settle differences between notes.

This supports a recent-visits default with a place filter. It is a bounded
observation, not evidence that every research workflow favors recency. The
accepted behavior and revised working practice are maintained in
[the project account](../project.md). The review now judges the complete reading
task and preservation of differences as well as navigation effort. The selected
default-view design task is complete; implementation and broader usability
claims need their own evidence. The worksheet's useful content is retained in
the evidence account, so its temporary coordination can be released.

## Remaining question

After selecting a place, should a reader compare visits in a combined view or
open separate notes? The walkthrough did not distinguish those options. Try a
comparison involving conflicting observations before committing to either.
For now, ordinary notes remain individually readable.
